# movie-app

영화 정보를 조회하고 리뷰를 남길 수 있는 웹 애플리케이션입니다.

## 기능

- 영화 목록 조회 및 장르별 필터 (SF / 드라마 / 액션 / 로맨스)
- 찜하기 및 찜한 영화만 보기
- 영화 등록 · 수정 · 삭제
- 영화별 리뷰 작성 및 삭제
- 평점순 베스트 목록

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 프론트엔드 | React, TypeScript |
| 라우팅 | React Router |
| 빌드 도구 | Vite |
| 로컬 API | json-server (`db.json`) |
| 개발 환경 | Ubuntu 24.04, VS Code Remote-SSH |

## 실행 방법

터미널 **2개**가 필요합니다.

```bash
npm install
```

```bash
# 터미널 1 - API 서버 (포트 4000)
npx json-server db.json --port 4000
```

```bash
# 터미널 2 - 화면 서버
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

> 외부 API 대신 `db.json`을 로컬 목업 데이터로 사용합니다.

## 만든 방법

생성형 AI를 활용해 개발했습니다. 화면 구성과 기본 로직은 AI로 빠르게 작성하고,
생성된 코드를 직접 실행하며 동작을 확인하고 수정했습니다.

## 직접 확인하고 수정한 부분

AI가 생성한 코드를 그대로 두지 않고, 예외 상황을 하나씩 직접 실행해 확인했습니다.

| 확인 항목 | 결과 |
|---|---|
| 영화 등록 시 필수값 누락 | 정상 — 경고 후 등록 차단 |
| 평점 입력 범위 | 정상 — 1.0~5.0 선택만 가능 |
| 영화 삭제 | 정상 — 확인창 표시 |
| 리뷰 작성 시 빈 값 | 정상 — 경고 후 등록 차단 |
| 존재하지 않는 페이지 | 정상 — 404 화면 표시 |
| **API 서버 미응답** | **문제 발견** |

입력값 검증과 404 처리는 잘 되어 있었지만,
**API 서버가 응답하지 않을 때 화면에 아무 안내도 표시되지 않는 문제**를 발견했습니다.
헤더와 버튼은 그대로 보이는데 목록 영역만 비어 있어,
사용자는 데이터가 없는 것인지 오류인지 구분할 수 없는 상태였습니다.

AI가 만든 코드는 정상적인 흐름은 잘 처리하지만,
외부 의존성이 끊어진 상황까지 고려하지는 않는다는 것을 확인했습니다.
